# NovaNest – Premium Real Estate Experience

![Landing Page](./landing.png)

## Overview
NovaNest is a completely revamped, production-ready premium real estate full-stack application. Developed with a strict luxury white-themed aesthetic (`#EEEEEE` backgrounds, `#222831` typography, `#00ADB5` accents), it features cutting-edge interaction design perfectly linked to a scalable Node.js backend.

## Structure
- `/backend`: Scalable Node.js, Express, and MongoDB backend supporting authentication, properties and dynamic data.
- `/frontend`: React/Vite premium Single Page frontend with Framer Motion reveals.

## Features
- **Intelligent Navbar**: Includes smooth scroll anchored navigation with an IntersectionObserver tracking active viewing sections.
- **Premium Auth Portal (`/auth`)**: Isolated luxury authentication page with seamless transitions between Login and Registration, including complete form validation.
- **Dynamic Property Viewing**: Interactive high-resolution property grids with tactile lifting hover states and dedicated detailed action hooks.
- **Immersive Global Locations**: Beautiful image-anchored location selectors featuring slow-zooms and dark gradient overlays.

## Tech Stack
- Frontend: React (Vite-optimized), Tailwind CSS, Framer Motion, React Router DOM
- Backend: Node.js, Express, MongoDB, Redis, JWT

## Setup & Installation
```bash
# Backend Setup
cd backend
npm install
npm start

# Frontend Setup
cd frontend
npm install
npm run dev
```
